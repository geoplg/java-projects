# java-projects

A simple <ins>Tic Tac Toe</ins> game built with Java Swing, featuring a graphical interface and a scoreboard.

## ⚡ Features
- **2-player gameplay**: Play X vs O on a 3x3 grid.
- **Turn tracking**: Shows whose turn it is.
- **Win detection**: Detects row, column, and diagonal wins.
- **Draw detection**: Alerts when the board is full with no winner.
- **Scoreboard**: Keeps track of X and O wins across multiple rounds.
- **Automatic reset**: Board resets after a win or a draw, preserving the scores.
- **Simple UI**: Clean, responsive interface using JFrame, JPanel, and JButton.

## ⚙️ How it works
- Click a button to mark X or O.
- The program checks for a win or draw after every move.
- The scoreboard updates automatically.
- The game continues until you close the window.

## 🛠️ Technologies
- Java 8
- Swing GUI
